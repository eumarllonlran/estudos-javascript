# 01 · HTML

Estrutura das páginas web.

## Tópicos

- ✅ Estrutura básica de um documento (`<!DOCTYPE>`, `<head>`, `<body>`)
- ✅ Tags semânticas (`<header>`, `<main>`, `<section>`, `<footer>`)
- ✅ Formulários (`<form>`, `<label>`, `<input>`, `<select>`, `<textarea>`)
- ✅ Agrupar campos com `<fieldset>` e `<legend>`
- ✅ Validação nativa (`required`, `minlength`, `maxlength`, `type="email"`)
- ✅ Acessibilidade básica (`aria-describedby`, `alt`, rótulos ligados aos campos)
- ⬜ Tabelas
- ⬜ Áudio e vídeo
- ⬜ SEO básico (meta tags)
